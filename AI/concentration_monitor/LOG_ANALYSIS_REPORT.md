# 📊 AI Focus Monitor 로그 분석 리포트

## 1. 분석 개요
*   **분석 대상 파일**: `monitor_log_20260125_211534.csv`
*   **분석 목적**: 핸드폰 사용 감지 로직 개선(0.6 -> 0.4 임계값 하향 및 손 인식 범위 확대) 후 성능 검증.

## 2. 비교 분석 (Before & After)
성능 개선 효과를 증명하기 위해 **튜닝 전(Before)**과 **튜닝 후(After)** 로그를 비교하는 것이 가장 효과적입니다.

### ❌ Before: 튜닝 전
*   **파일**: `monitor_log_20260125_211058.csv` (약 21:10 생성)
*   **문제점**: 핸드폰을 보고 있음에도 `phone_conf`가 낮아 무시되거나, 고개를 숙였다는 이유로 `DROWSY`(졸음)로 오인식됨.
*   **증상**: `PHONE` 상태가 불안정하게 깜빡이거나 `DROWSY`로 기록됨.

### ✅ After: 튜닝 후
*   **파일**: `monitor_log_20260125_211534.csv` (약 21:15 생성)
*   **개선점**:
    1.  **손 인식 범위 확대**: 핸드폰 확신도가 낮아도(0.1~0.2) **손이 근처에 있으면 즉시 감지**.
    2.  **우선순위 변경**: 눈이 감겨 있어도(졸음 점수 높음), **핸드폰 사용이 감지되면 `PHONE`을 우선**하여 기록.
*   **결과**: 핸드폰을 드는 순간부터 내려놓을 때까지 끊김 없이 `PHONE` 상태 유지.

---

## 3. 주요 데이터 상세 (Key Findings)

#### [사례 2] 우선순위 로직 작동 확인 (Lines 674 ~ 715)
*   **상황**: 핸드폰을 보느라 고개를 약간 숙임 (`pitch` ~ 0.2) + 눈이 가늘어짐.
*   **데이터**:
    *   `drowsy_score`: 1.0 (졸음 의심 점수 높음)
    *   **`state`**: **`PHONE`** 
*   **성과**: 졸음 점수가 높았음에도 불구하고, 핸드폰 사용(`phone_in_use`)을 **우선순위**로 두도록 로직을 수정한 덕분에 **"졸음"으로 오인하지 않고 "핸드폰 사용"으로 정확히 기록**되었습니다.

## 3. 결론
*   **튜닝 성공**: "핸드폰 인식이 둔하다"는 문제를 해결하기 위해 적용한 **[손 인식 범위 확대]**와 **[우선순위 변경]**이 실제 환경에서 의도대로 작동함을 확인했습니다.
*   **신뢰도 확보**: 이제 핸드폰을 책상에 두지 않고 손에 들고만 있어도 즉각 감지합니다.
